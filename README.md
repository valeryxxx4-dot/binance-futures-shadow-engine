# 🦅 Binance Futures Shadow Engine v4.0

> **Zero-Risk Multi-Strategy Algorithmic Simulation & Forward-Testing Engine for Binance USDT-M Futures**  
> Автономный теневой полигон для непрерывного параллельного форвард-тестирования алгоритмических торговых систем на живых рыночных потоках Binance Futures без финансового риска.

---

## 📌 1. Для чего создана эта система (Mission & Philosophy)

В классическом алгоритмическом трейдинге существует огромный разрыв между историческим бэктестом (где результаты часто завышены из-за переобучения и нереалистичных допущений об исполнении) и реальной торговлей (где на первый план выходят проскальзывания, задержки сокетов, токсичный стакан, перегретый фандинг и микроструктура рынка).

**Shadow Engine решает ключевые задачи:**
1. **Zero-Risk Forward-Testing (Форвард-тест без риска):**
   - Движок подключается к реальным боевым WebSocket-потокам Binance Futures (`wss://stream.binancefuture.com/stream`).
   - Исполнение ордеров (Limit, Market, Stop-Loss, Take-Profit, Trailing Stops) рассчитывается на базе реальных котировок лучших цен покупки/продажи (Bid/Ask) и динамической глубины стакана 20 уровней (`depth20@100ms`).
   - Учитываются реальные биржевые комиссии (Maker `0.02%`, Taker `0.05%`) и требования к проникновению цены для лимитных ордеров.
2. **Параллельное соревнование 4 гетерогенных стратегий (Tournament Mode):**
   - Каждая стратегия стартует с изолированным субсчетом (по умолчанию **$100.00 USDT**).
   - Ведется раздельный учет баланса, эквити, реализованного PnL, уплаченных комиссий, числа сделок и винрейта (Win Rate).
   - Система позволяет объективно сравнить, какая из математических моделей лучше адаптируется к текущему рыночному режиму.
3. **Защита от банов REST API:**
   - Все рыночные данные (свечи 5m, 15m, 1h и стаканы 100ms) агрегируются через **единое мультиплексное WebSocket-соединение (7 потоков)**. 
   - REST API используется исключительно один раз при старте для предзагрузки исторических свечей.
4. **Институциональная система пре-трейд и пост-трейд риск-менеджмента:**
   - Контроль волатильности (CVaR ATR).
   - Защита от токсичного дисбаланса книги заявок (OBI Filter).
   - Защита от токсичного микропотока (Signed Midpoint Markout / SMM Guard).
   - Защита от контртрендовых входов на развивающейся часовой свече (Hour-Open Anti-Counter Filter).
   - Адаптивные временные стопы (Adaptive Time-Stop с периодом Grace Period).

### 1️⃣ DLH (Daily Liquidity Hunter — ETHUSDT 1H/15M)
- **Концепция:** Торговля ложных пробоев (свипов) суточных экстремумов предыдущего дня (PDH — Previous Day High, PDL — Previous Day Low).
- **Логика входа:** Свеча прокалывает суточный уровень на глубину от $3.0 до $15.0 USDT, но закрывается обратно внутрь диапазона, демонстрируя отказ цены идти дальше.
- **Защита капитала:** Фильтр `max_sweep_depth <= 15.0$` мгновенно блокирует контртрендовые сделки при истинных вертикальных трендовых импульсах.
- **Выход:** Расчетный SL за экстремум фитиля, частичная фиксация TP1 (50%), трейлинг-стоп Ratchet Trailing на остаток объема.

### 2️⃣ HRB (High-Volume Range Breakout — ETHUSDT 15M)
- **Концепция:** Импульсный пробой 20-периодного диапазона Donchian Channel.
- **Логика входа:** Закрытие свечи за границей канала Donchian с полнотелым телом (тело свечи $\ge 60\%$ от общего диапазона) и всплеском торгового объема $\ge 1.8	imes$ относительно 20-периодной средней объема (SMA20).
- **Выход:** Трейлинг-стоп на базе Chandelier Exit ($2.0	imes$ ATR) и Stop-Loss ($1.5	imes$ ATR).

### 3️⃣ ARGUS BTC (LightGBM Machine Learning — BTCUSDT 15M)
- **Концепция:** Квантовый ML-классификатор на базе градиентного бустинга LightGBM.
- **Входные признаки (25 относительных фичей):** Соотношения тел и фитилей, лаги доходностей, Directional Bias Score (DBS), RSI-14, скользящие средние, Z-score объема, Whale Score, метрики энергопотока рынка.
- **Пре-трейд фильтры (Guard Stack):**
  - **Порог вероятности:** Настраиваемый порог уверенности модели (`prob_threshold: 0.55`).
  - **CVaR ATR Guard:** Запрет входа при аномальной волатильности ($ATR > 320.0$).
  - **OBI Filter:** Проверка дисбаланса книги заявок (вход разрешен только при $OBI \in [-0.60, +0.90]$).
  - **Hour-Open Anti-Counter Filter:** Запрет шорта, если текущий час растет более чем на $+0.15\%$; запрет лонга, если текущий час падает более чем на $-0.15\%$. Защищен от дрейфа базовой цены часа.
  - **SMM Guard (Signed Midpoint Markout):** Анализ микротоксичности котировок за 10 секунд.
- **Адаптивный тайм-стоп (Adaptive Time-Stop):** Если позиция не выходит в плюс за 90 минут, активируется Grace Period (до 45 минут) с жестким трейлингом в безубыток при первом отскоке.

### 4️⃣ JAZZ (Dynamic 6H Corridor Sweep — ETHUSDT 5M)
- **Концепция:** Реплика высокочастотной стратегии на 5-минутных свечах с 6-часовым скользящим окном (72 свечи).
- **Логика входа:** Пробой границы 6-часового коридора с формированием отбойной свечи (фитиль $\ge 0.8	imes$ тела свечи).
- **Dead Zone Filter:** Закрытие свечи должно быть за пределами центральных 30% коридора.
- **Менеджмент позиции:** Early Breakeven (перевод в безубыток при смещении цены на $4.50 USDT), Dynamic Compression (сжатие шага трейлинга при подходе к цели) и ступенчатый квантованный трейлинг.

## 🚀 4. Быстрый старт и запуск

### Требования
- Python 3.10+
- ОС Windows / Linux / macOS
- Установленные зависимости

### Установка
```bash
git clone https://github.com/valeryxxx4-dot/binance-futures-shadow-engine.git
cd binance-futures-shadow-engine

# Создание виртуального окружения
python -m venv venv

# Активация
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### Запуск тестов (Unit & Integration Tests)
Комплекс тестов проверяет математику всех 4 стратегий, расчет признаков LightGBM, логику брокера, расчет комиссий и защиту от дрейфа:
```bash
python -m unittest test_simulation_integration.py
```
*Все 19 интеграционных тестов должны завершиться статусом `OK`.*

### Запуск смоук-теста подключения к Binance Futures
Проверяет подключение к живым потокам WebSocket:
```bash
python test_live_smoke.py
```

### Запуск полигона в режиме реального времени
```bash
# Windows (в отдельном окне):
start_shadow_dashboard.bat

# Или напрямую через Python:
python shadow_runner.py
```

## 🔒 5. Безопасность (Security & Zero-Leak Guarantee)

- В репозитории **отсутствуют любые API-ключи, токены или приватные данные**.
- Все сетевые запросы используют **публичные неаутентифицированные потоки данных Binance Futures**:
  - WebSocket: `wss://stream.binancefuture.com/stream`
  - REST klines: `https://fapi.binance.com/fapi/v1/klines`
- Реальная отправка биржевых ордеров физически исключена: исполнение эмулируется внутренним движком `VirtualBroker`.
